# Aula 1 (2/2): escreva o plano do seu orquestrador de agentes

**O que você terá no fim:** Um `plano.md` escrito pelo agente, que descreve o Regente, o orquestrador com quem você conversa, com o quiz de cinco perguntas e o menu de opções.

## Antes de começar

- Zed aberto na pasta agente-de-vagas
- OpenRouter configurado (Aula 1, parte 1)
- Um modelo gratuito escolhido no painel do agente
- Objetivo: buscar vagas de tecnologia
