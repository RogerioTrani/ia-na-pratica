# Aula 3: crie o Prumo, o agente que ranqueia as vagas

**O que você terá no fim:** O Prumo, o terceiro agente: lê as vagas do Faro e o perfil e devolve só as melhores, com nota de 0 a 100, pontos fortes, lacunas e motivo.

## Antes de começar

- Zed aberto na pasta agente-de-vagas
- OpenRouter com um modelo gratuito
- Regente e Faro funcionando
- Perfil na pasta data
- Resultados da busca preenchidos pelo Faro
- plano.md e plano-aula-2.md no projeto
