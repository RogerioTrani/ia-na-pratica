# Microsoft lança MAI Code 2 no Ignite, em São Francisco

_2026-11-20 · noticia_

Na terça-feira (17), durante o Microsoft Ignite, em São Francisco, a Microsoft apresentou uma família de modelos próprios de IA: MAI Code 2 (programação), MAI Cyber 2 Flash (cibersegurança), MAI Image 2.7 (imagem) e MAI Transcribe 2 (transcrição de áudio). O MAI Code 2 já está no GitHub Copilot. Segundo Mustafa Suleyman, chefe de IA da Microsoft, a aposta em modelos especializados equilibra desempenho e preço.

## O anúncio

A Microsoft usou o Ignite, em São Francisco, para apresentar uma família de modelos de IA desenvolvidos dentro da empresa. Cada um foi pensado para um tipo de tarefa: programação, segurança, imagem e áudio.

A Microsoft segue parceira da OpenAI e, ao mesmo tempo, investe em tecnologia própria.

Fonte: <https://olhardigital.com.br/2026/11/17/inteligencia-artificial/microsoft-lanca-ia-propria-para-competir-com-openai-e-anthropic/>

## MAI Code 2: programação

O MAI Code 2 é o destaque da família e já está disponível no GitHub Copilot.

Em quatro testes feitos pela própria Microsoft, ele entrega 98% do desempenho do GPT-6.1 Sol por 40% do custo. Os números vêm da empresa, não de avaliação independente.

Fonte: <https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/>

## MAI Cyber 2 Flash: cibersegurança

O modelo chega a partir de meados de dezembro, para clientes elegíveis dos produtos de segurança da Microsoft.

Ele mira o aumento de vulnerabilidades em software, um problema que as próprias ferramentas de IA têm ajudado a identificar.

Fonte: <https://microsoft.ai/news/introducing-mai-cyber-2-flash/>

## MAI Image 2.7 e MAI Transcribe 2

Os dois modelos completam a família e foram desenvolvidos internamente. O MAI Image 2.7 trabalha com geração de imagens. O MAI Transcribe 2 faz transcrição de áudio.

- MAI Image 2.7: prévia pública no Microsoft Foundry. Anúncio: https://microsoft.ai/news/introducing-mai-image-2-7/
- MAI Transcribe 2: prévia limitada no MAI Labs. Página: https://microsoft.ai/models/mai-transcribe-2/

Fonte: <https://microsoft.ai/news/introducing-mai-image-2-7/>

## Onde cada modelo está

- MAI Code 2: já no GitHub Copilot.
- MAI Cyber 2 Flash: a partir de meados de dezembro, para clientes elegíveis dos produtos de segurança da Microsoft.
- MAI Image 2.7: prévia pública no Microsoft Foundry.
- MAI Transcribe 2: prévia limitada no MAI Labs.

## A estratégia: modelos especializados

Em entrevista à Reuters, Mustafa Suleyman, chefe da divisão de IA da Microsoft, disse que a empresa concentra recursos em tarefas específicas em vez de depender de um único modelo generalista. Para ele, isso equilibra desempenho e preço.

A Microsoft mantém a parceria com a OpenAI e agora quer mostrar que também consegue competir com sistemas próprios.

Fonte: <https://olhardigital.com.br/2026/11/17/inteligencia-artificial/microsoft-lanca-ia-propria-para-competir-com-openai-e-anthropic/>

## Além do vídeo

- Suleyman disse que a abordagem chega a resultados próximos ou superiores aos de concorrentes em alguns testes de referência.
- Suleyman descreveu o sistema como uma estrutura para melhorar continuamente a relação entre desempenho e custo, e afirmou: "Isso não é apenas um modelo. Não é algo passageiro".
- Segundo Suleyman, os riscos do uso de IA para achar e explorar vulnerabilidades passaram a ocupar lugar central na estratégia da Microsoft.
- Ele citou o episódio em que agentes de IA da OpenAI invadiram a plataforma Hugging Face como exemplo de uso prejudicial de ferramentas automatizadas.
- Uma das prioridades de Suleyman é impedir que os modelos executem ações prejudiciais e garantir que se comportem como esperado, área conhecida como alinhamento de IA.
