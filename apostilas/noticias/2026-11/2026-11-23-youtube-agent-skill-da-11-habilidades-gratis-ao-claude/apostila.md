# YouTube Agent Skill dá 11 habilidades grátis ao Claude

_2026-11-23 · noticia_

O YouTube Agent Skill é um pacote de código aberto com onze habilidades para o Claude que assumem parte do trabalho de produção de um canal. Entre elas estão o roteiro com cinco ganchos avaliados com nota, o relatório de retenção e a comparação dos vídeos do nicho com a mediana do próprio canal. A licença é MIT, não pede chave de API e instala com dois comandos no Claude Code.

## O que é o pacote

O YouTube Agent Skill reúne onze habilidades do Claude que cuidam de parte do trabalho de rodar um canal no YouTube. Todas são gratuitas.

As três habilidades abaixo são as que este material detalha.

Fonte: <https://github.com/Jakeschincariol/youtube-agent-skill>

## Roteiro com cinco ganchos

Você dá a ideia do vídeo e recebe o roteiro com cinco ganchos diferentes, cada um com nota. A nota permite escolher o melhor gancho antes de ligar a câmera, para não gastar uma gravação com um gancho fraco.

Fonte: <https://github.com/Jakeschincariol/youtube-agent-skill>

## 21 fórmulas de gancho

A habilidade de roteiro parte de 21 fórmulas de gancho e dá nota ao gancho antes da gravação.

Fonte: <https://github.com/Jakeschincariol/youtube-agent-skill>

## Relatório de retenção

Você envia o relatório de retenção do vídeo e a habilidade mostra o segundo exato em que o público foi embora. Com isso você sabe o que corrigir no vídeo seguinte.

Fonte: <https://github.com/Jakeschincariol/youtube-agent-skill>

## Comparação com a mediana do canal

Cada vídeo do nicho é comparado com a mediana do próprio canal, para mostrar o que funciona. Os vídeos ficam ordenados pelo quanto superaram essa mediana, sem depender do tamanho do canal. Assim você aproveita ideias que já deram certo.

Fonte: <https://raw.githubusercontent.com/Jakeschincariol/youtube-agent-skill/main/README.md>

## Como instalar no Claude Code

O projeto tem licença MIT e não usa chave de API nem cadastro. Rode os dois comandos na ordem: o primeiro adiciona o pacote e o segundo instala as habilidades.

- Adicione o pacote com o primeiro comando.
- Instale as habilidades com o segundo comando.
