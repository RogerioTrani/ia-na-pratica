# Code Storage seguirá disponível após a aquisição

_2026-11-21 · noticia_

A OpenAI anunciou em 4 de novembro de 2026 a compra da Pierre Computer Company, dona do Code Storage (code.storage) e das bibliotecas open-source Trees e Diffs. A OpenAI quer levar as tecnologias da Pierre para o Codex. Quem usa o Code Storage pode continuar usando depois do fechamento, e os projetos open-source seguem abertos. O negócio ainda depende de aprovações regulatórias.

## O fato

Em 4 de novembro de 2026, a OpenAI anunciou que vai adquirir a Pierre Computer Company, Inc., empresa por trás do Code Storage e de um conjunto de ferramentas open-source para desenvolvedores.

Quem já navegou por arquivos ou revisou uma alteração no app do Codex já usou as bibliotecas Trees e Diffs, da Pierre. Fonte: https://openai.com/index/openai-to-acquire-pierre/

Fonte: <https://openai.com/index/openai-to-acquire-pierre/>

## Por que a OpenAI quer a Pierre

A OpenAI quer construir sobre os fluxos de trabalho com Git que os desenvolvedores já usam e adaptá-los a times que trabalham com agentes de código. A meta declarada é definir o padrão do desenvolvimento de software moderno, do primeiro branch criado por um agente até o código no ar.

A empresa quer que o Codex seja o lugar onde desenvolvedores e agentes tocam seus projetos mais ambiciosos. Codex: https://chatgpt.com/codex

Fonte: <https://openai.com/index/openai-to-acquire-pierre/>

## O que a Pierre entrega

Quatro produtos compõem a oferta da Pierre. Fonte: https://diffs.com/highlights

- Code Storage (code.storage): serviço que permite a apps guardar código e acompanhar o histórico usando Git.
- Trees (trees.software): navegação rápida pelos arquivos de um projeto.
- Diffs (diffs.com): mostra o que mudou. O modo Edit deixa o revisor corrigir a linha no ponto em que encontrou o problema.
- Highlights (@pierre/highlights, diffs.com/highlights): realçador de sintaxe muito rápido, que acompanha quem digita ou um agente que escreve código.

Fonte: <https://diffs.com/highlights>

## O que muda para clientes e comunidade

Clientes poderão continuar usando o Code Storage depois do fechamento, enquanto a OpenAI trabalha para levar as funcionalidades dele para dentro do Codex.

Os projetos open-source da Pierre, como Trees e Diffs, vão permanecer abertos, e a OpenAI continuará contribuindo com eles.

Fonte: <https://openai.com/index/openai-to-acquire-pierre/>

## O que conferir

Situação do negócio: o fechamento está sujeito a condições habituais, incluindo aprovações regulatórias. Até lá, OpenAI e Pierre seguem como empresas separadas e independentes.
