# Meta libera a Astryx, biblioteca usada em 13 mil apps

_2026-11-22 · noticia_

A Meta abriu ao público a Astryx, o sistema de design que cresceu dentro da empresa em oito anos e já está em mais de 13 mil apps. São componentes React agrupados em famílias, com licença MIT, e exigem React 19 ou superior. A CLI grava o índice de componentes no arquivo de instruções do agente de código.

## O fato

A Astryx é um sistema de design open source que nasceu dentro da Meta. Em oito anos de uso, virou o maior e mais usado sistema de design da empresa.

Mais de 13 mil apps usam a biblioteca. Quem a moldou foram engenheiros, designers e times de produto que dependem dela todo dia. Fonte: https://github.com/meta/astryx

Fonte: <https://github.com/meta/astryx>

## O que ela traz

São componentes React prontos, agrupados em famílias, para montar interface e experiência de uso com consistência. Se você cria apps com vibe coding e trava na parte visual, é um ponto de partida para ajustar as telas. Guia de início rápido: https://github.com/meta/astryx/blob/main/packages/core/README.md

- Componentes de interface React organizados por família.
- Exige React 19 ou superior: confira a versão do seu projeto antes de instalar.

Fonte: <https://github.com/meta/astryx/blob/main/packages/core/README.md>

## Licença e custo

A Astryx usa a licença MIT. Qualquer pessoa pode usar a biblioteca nos próprios projetos, pessoais ou de produção, sem pagar. Fonte: https://github.com/meta/astryx

Fonte: <https://github.com/meta/astryx>

## Como instalar a CLI

A CLI é instalada como dependência de desenvolvimento. O comando init grava o índice de componentes no AGENTS.md ou no CLAUDE.md do projeto. Com isso, o seu agente de código lê a documentação da biblioteca e escolhe os componentes que servem ao seu app. Pacote no npm: https://www.npmjs.com/package/@astryxdesign/core

1. rode o primeiro comando na pasta do projeto para instalar a CLI. Resultado: a CLI fica instalada como dependência de desenvolvimento.
2. rode o segundo comando para gravar o índice de componentes no arquivo de instruções do agente. Resultado: o agente lê a documentação e escolhe os componentes.

Fonte: <https://github.com/meta/astryx/blob/main/packages/core/README.md>
