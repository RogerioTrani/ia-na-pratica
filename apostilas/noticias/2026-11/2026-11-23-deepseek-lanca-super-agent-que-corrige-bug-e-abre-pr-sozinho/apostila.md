## O fato

A DeepSeek mostrou duas novidades: um agente aberto que corrige bugs a partir de um pedido no chat e um modo que transforma uma frase em aplicativo. O Super-Agent monitora o repositório e age quando alguém do time pede ou quando uma regra do time permite.

Ambos ainda estão em fase inicial, o Super-Agent é protótipo de pesquisa e o DeepSeek Harness está em developer preview. Fonte: https://github.com/deepseek-ai/dsh-superagent-prototype

Fonte: <https://github.com/deepseek-ai/dsh-superagent-prototype>

## O que é o Super-Agent

O Super-Agent é um agente aberto da DeepSeek que monitora o repositório do time. Ele age quando alguém do time pede no chat ou quando uma regra do time permite.

Fonte: <https://github.com/deepseek-ai/dsh-superagent-prototype>

## Bug no chat vira pull request

Um bug cai no chat do time. O agente reproduz o problema, corrige e abre o pull request sozinho. Quem reportou o erro já encontra a correção pronta para revisão; o time só precisa olhar o pull request e decidir se aceita.

Fonte: <https://github.com/deepseek-ai/dsh-superagent-prototype>

## Equipe de funcionários digitais

Um roteador distribui o trabalho entre funcionários digitais. Cada um guarda o próprio contexto. O trabalho continua com o notebook fechado.

Fonte: <https://github.com/deepseek-ai/dsh-superagent-prototype>

## Creator Mode: uma frase vira um app

No Creator Mode, você descreve a ideia em uma frase e o modo de criação monta o aplicativo. Os exemplos mostrados vão de um mural de post-its a um jogo de voxels, um editor de vídeo e um guia de viagem em 3D. Fonte: https://github.com/deepseek-ai/deepseek-harness

Fonte: <https://github.com/deepseek-ai/deepseek-harness>

## Plugin da comunidade: dsh-claude-design

Há um plugin da comunidade que roda o fluxo do Claude Design no DeepSeek Harness. Pacote no npm: https://registry.npmjs.org/dsh-claude-design

