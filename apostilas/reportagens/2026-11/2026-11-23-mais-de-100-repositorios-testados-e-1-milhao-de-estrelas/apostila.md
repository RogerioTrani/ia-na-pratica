## Remotion: vídeo com React e TypeScript

Transforma código em vídeo usando React e TypeScript. Tem recursos voltados também para edição. Por usar React e TypeScript, é mais pesado e gasta mais tokens que o Hyperframes. Comando para criar o projeto:

```
npx create-video@latest
```

Fonte: <https://github.com/remotion-dev/remotion>

## Hyperframes: vídeo com HTML, CSS e JavaScript

Transforma código em vídeo com HTML, CSS e JavaScript. Gasta menos tokens que o Remotion e serve melhor para gerar motion do que para cortar e limpar um vídeo gravado. Antes de começar, instale o Node.js 22 ou mais e também o FFmpeg.

1. instale o Node.js 22 ou mais. Resultado: o ambiente atende ao requisito.
2. instale também o FFmpeg. Resultado: o FFmpeg fica disponível.
3. rode o comando abaixo para criar o projeto. Resultado: o projeto my-video é criado.

```
npx hyperframes init my-video
```

Fonte: <https://github.com/heygen-com/hyperframes>

## Voice Studio: voz clonada e dublagem grátis

Alternativa gratuita e open source ao ElevenLabs. Clona a sua voz, gera áudios com ela e dubla vídeos para outro idioma. Roda no seu computador, com instaladores para Windows, Mac e Linux.

No teste do canal, funcionou melhor que o esperado, inclusive em português. Não supera as opções pagas, mas atende quem quer algo gratuito e ilimitado, rodando num servidor. Repositório: https://github.com/debpalash/VoiceStudio

Fonte: <https://github.com/debpalash/VoiceStudio>

## Paperclip: um time de agentes

Monta um time de agentes que trabalham juntos, cada um com contexto e tarefas próprios. É gratuito e se usa pela interface. Também permite montar um conselho de modelos que debatem um tema até chegar a um resultado refinado. Repositório: https://github.com/paperclipai/paperclip

1. instale antes o Node.js 24.11 ou mais. Resultado: o ambiente atende ao requisito.
2. rode o comando abaixo e siga o onboarding pela interface. Resultado: o Paperclip fica configurado.

```
npx paperclipai@latest onboard --yes
```

Fonte: <https://github.com/paperclipai/paperclip>

## Superpowers: o ciclo do projeto, do plano ao teste

Ajuda programadores a planejar, construir, revisar e testar projetos. A v7.0.2, de 3 de novembro de 2026, cortou as perguntas de enchimento do brainstorming de 41 para 23 nos testes do projeto. Repositório: https://github.com/obra/superpowers

1. no Claude Code, rode o comando abaixo. Resultado: o plugin Superpowers é instalado.

```
/plugin install superpowers@claude-plugins-official
```

Fonte: <https://github.com/obra/superpowers>

## Reverse Engineer Anything: estudar um aplicativo

Dá a agentes de IA um jeito de estudar um aplicativo e recriar suas funções. Reúne informações de várias fontes e, a partir delas, começa o desenvolvimento. Nos testes do canal, a coleta de informações foi o ponto forte. A etapa de desenvolvimento do aplicativo ficou abaixo disso, principalmente para quem já trabalha com IA agêntica mais sofisticada. Repositório: https://github.com/morluto/rea

```
npx rea-agents setup
```

Fonte: <https://github.com/morluto/rea>
