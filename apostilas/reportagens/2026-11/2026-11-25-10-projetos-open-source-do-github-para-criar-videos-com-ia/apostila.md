# 10 projetos open source do GitHub para criar vídeos com IA

_2026-11-25 · reportagem_

Dez projetos open source no GitHub montam um estúdio de vídeo com IA. Você transcreve, legenda, edita e publica em código aberto, do áudio ao Short pronto para publicar. Cada ferramenta tem o endereço do repositório logo abaixo.

## Open Chat Cut

Edita vídeo por comandos em linguagem natural. Escreva o que você quer e o projeto faz a edição.

- Descreva a edição em linguagem natural.
- Rode pelo repositório.

```
github.com/0xsline/OpenChatCut
```

Fonte: <https://github.com/0xsline/OpenChatCut>

## Whisper

Transcreve áudio e vídeo com interface web e vários modelos de reconhecimento.

- Escolha entre os modelos de reconhecimento.
- Rode pelo repositório.

```
github.com/pluja/anysub
```

Fonte: <https://github.com/pluja/anysub>

## AI Video Transcriber

Transcreve vídeos, extrai diálogos e transforma gravações em texto.

- Instale pelo repositório.
- Transforme o áudio das gravações em texto.

```
github.com/wendy7756/AI-Video-Transcriber
```

Fonte: <https://github.com/wendy7756/AI-Video-Transcriber>

## Open Storyline

Entende a narrativa do vídeo e organiza a estrutura entre cenas.

- Organize a estrutura entre uma cena e outra.
- Use pelo repositório.

```
github.com/FireRedTeam/FireRed-OpenStoryline
```

Fonte: <https://github.com/FireRedTeam/FireRed-OpenStoryline>

## Easel

Usa modelos avançados de IA para criar, tratar e editar conteúdo visual.

- Trate o material em código aberto.
- Rode pelo repositório.

```
github.com/ZJU-REAL/Easel
```

Fonte: <https://github.com/ZJU-REAL/Easel>

## Auto Subs

Gera e sincroniza legendas automáticas a partir de áudio e vídeo, com alta precisão.

- Instale no repositório.
- Sincronize as legendas com o vídeo.

```
github.com/tmoroney/auto-subs
```

Fonte: <https://github.com/tmoroney/auto-subs>

## Stickman Video Director

Cria e dirige vídeos animados com personagens Stickman e narrativas visuais.

- Monte a animação com personagens Stickman.
- Rode pelo repositório.

```
github.com/kaomei/stickman-video-director
```

Fonte: <https://github.com/kaomei/stickman-video-director>

## Produção e publicação automatizada

YouTube Automation Agent é um agente de IA que automatiza a produção de vídeos para o YouTube. LinkedIn Skills reúne skills para pesquisa, redação e publicação de conteúdo no LinkedIn. AI YouTube Shorts Generator transforma ideias em vídeos verticais prontos para publicar.

- Instale o YouTube Automation Agent pelo repositório.
- Instale o LinkedIn Skills pelo repositório.
- Acesse o repositório do AI YouTube Shorts Generator.
