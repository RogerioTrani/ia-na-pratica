# Harness Leaderboard compara 9 harnesses com 28.849 testes

_2026-11-24 · reportagem_

O Harness Leaderboard, criado por Joël Niklaus, compara nove harnesses de agentes de código rodando modelos abertos. O ranking sai de 28.849 testes. Em cada comparação só o harness muda, então a diferença no resultado vem dele. Serve para quem programa com modelo aberto e precisa escolher em qual harness rodar.

## O que é o Harness Leaderboard

Harness é a camada que cerca o modelo e organiza o trabalho do agente de código. Quem usa modelo aberto para programar escolhe o modelo e também o harness.

O Harness Leaderboard, criado por Joël Niklaus, compara nove harnesses de agentes de código rodando modelos abertos. A ideia é responder com medição qual harness vale a pena, em vez de decidir por palpite.

Fonte: <https://huggingface.co/spaces/joelniklaus/harness-leaderboard/raw/main/README.md>

## Os números do ranking

O ranking sai de 28.849 testes rodados. É computação que você não precisa gastar de novo para chegar à comparação.

- 9 harnesses de agentes de código
- Modelos abertos
- 28.849 testes

## Como o teste foi desenhado

Em cada comparação, só o harness muda. O modelo fica o mesmo. Se o resultado muda, a causa é o harness e não outro fator.

Esse desenho é o que dá peso ao ranking.

## Como usar na sua escolha

Se você roda modelos abertos para programar, consulte o ranking antes de decidir o harness.

- Abra o Space oficial no Hugging Face.
- Compare os nove harnesses de agentes de código.
- Escolha o harness com base na medição, e não no palpite.
