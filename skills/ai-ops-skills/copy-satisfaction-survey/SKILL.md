# Pesquisa com compradores

Monta um questionário curto que gera retorno aproveitável de quem comprou. Use quando precisar entender a experiência, coletar melhorias ou checar se o cliente alcançou o que buscava.

## Antes de começar

Reúna, a partir do pedido e do arquivo de instruções do projeto (se houver):

- Decisão que a pesquisa deve informar
- Momento da jornada em que o cliente será consultado
- Hipótese sobre o que vai bem ou mal
- Canal de aplicação e tratamento dos dados

Se faltar algo decisivo, pergunte só o necessário. Se der para avançar, marque a lacuna e siga sem inventar dado.

## Passo a passo

1. Escreva a hipótese e escolha o momento em que o cliente já tem experiência suficiente para responder.
2. Elabore oito perguntas combinando escalas curtas com campos abertos, uma ideia por pergunta.
3. Separe as questões sobre satisfação com a experiência das que medem se o resultado foi atingido.
4. Revise a redação para não induzir resposta e peça permissão em separado caso o relato possa virar depoimento.
5. Descreva como ler cada resposta, que combinações pedem contato e o que não se pode concluir.

## O que entregar

Questionário de oito perguntas com escala definida e guia de interpretação.

## Conferência antes de entregar

- [ ] Cada pergunta alimenta uma decisão identificável.
- [ ] Nenhuma questão junta dois assuntos ou pressupõe que a experiência foi boa.
- [ ] Só são pedidos os dados pessoais indispensáveis.

## Limites

Só diga que publicou, enviou, testou ou alterou algo se isso aconteceu. Peça aprovação antes de ação externa, com custo ou que não dê para desfazer.
