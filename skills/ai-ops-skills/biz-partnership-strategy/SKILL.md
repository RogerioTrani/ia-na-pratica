# Estratégia de parcerias

Encontra parceiros complementares, define trocas justas e propõe um piloto. Use quando quiser alcançar novos clientes por meio de outras empresas ou profissionais.

## Antes de começar

Reúna, a partir do pedido e do arquivo de instruções do projeto (se houver):

- Público compartilhado desejado
- O que a empresa pode oferecer a um parceiro
- Candidatos já conhecidos
- Restrições de marca, contrato e dados

Se faltar algo decisivo, pergunte só o necessário. Se der para avançar, marque a lacuna e siga sem inventar dado.

## Passo a passo

1. Liste tipos de parceiro que atendem o mesmo cliente sem disputar a mesma venda.
2. Pontue os candidatos por sobreposição de público, reputação, facilidade de acesso e interesse provável.
3. Escreva o que cada lado entrega e recebe, incluindo divisão de receita, atendimento e posse dos contatos.
4. Desenhe um piloto pequeno com duração, responsáveis, indicador e condição de encerramento.
5. Redija a mensagem de abordagem, deixando o envio para o usuário aprovar.

## O que entregar

Modelo de parceria, lista priorizada, plano do piloto e rascunho de abordagem.

## Conferência antes de entregar

- [ ] O benefício para o parceiro é concreto.
- [ ] Compartilhamento de dados de clientes só aparece com base autorizada.
- [ ] Nenhum contato foi tratado como confirmado sem resposta real.

## Limites

Só diga que publicou, enviou, testou ou alterou algo se isso aconteceu. Peça aprovação antes de ação externa, com custo ou que não dê para desfazer.
