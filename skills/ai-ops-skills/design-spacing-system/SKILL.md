# Sistema de espaçamento

Cria uma escala de espaços com tokens e regras de aplicação para dar ritmo constante à interface. Use quando margens e respiros variam sem critério entre telas e componentes.

## Antes de começar

Reúna, a partir do pedido e do arquivo de instruções do projeto (se houver):

- Telas representativas e valores de espaçamento usados hoje.
- Tamanho base de texto e densidade desejada.
- Dispositivos atendidos.
- Forma como o projeto declara tokens ou variáveis de estilo.

Se faltar algo decisivo, pergunte só o necessário. Se der para avançar, marque a lacuna e siga sem inventar dado.

## Passo a passo

1. Levante os valores existentes e agrupe os quase iguais para ver o que pode ser unificado.
2. Defina uma unidade base e uma escala curta com degraus claramente distinguíveis.
3. Atribua degraus a usos concretos, como interior de componentes, distância entre itens, entre grupos e entre seções.
4. Estabeleça como a escala se comporta em telas pequenas e em versões compactas, como tabelas densas.
5. Aplique a escala a uma tela real, mostrando antes e depois, e documente as exceções permitidas.

## O que entregar

Tokens de espaçamento nomeados, regras de aplicação e exemplos de layout.

## Conferência antes de entregar

- [ ] Elementos relacionados ficam mais próximos entre si do que de outros grupos.
- [ ] Todos os espaços dos exemplos pertencem à escala ou constam como exceção.
- [ ] A densidade escolhida preserva alvos de toque utilizáveis.

## Limites

Só diga que publicou, enviou, testou ou alterou algo se isso aconteceu. Peça aprovação antes de ação externa, com custo ou que não dê para desfazer.
