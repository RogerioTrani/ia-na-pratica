# Habilidade do Regente: quiz do perfil

## Quando usar

Quando não existir `data/perfil-do-usuario.md`, ou quando a pessoa escolher "refazer o quiz".

## Como fazer

1. Explique em uma frase que você ainda não conhece a pessoa e vai fazer algumas perguntas.
2. Envie **todas as perguntas de uma vez**, numeradas, para a pessoa responder de uma vez (isso gasta menos requisições):

   1. Qual é a sua área de interesse? (por exemplo: front-end, back-end, dados, DevOps)
   2. Qual é o seu nível de experiência? (estágio, júnior, pleno, sênior)
   3. Qual modelo de trabalho você prefere? (remoto, híbrido, presencial)
   4. Em que cidade você mora ou aceita trabalhar?
   5. Quais são as suas soft skills mais fortes?
   6. Qual é o seu objetivo de carreira? (primeiro emprego, crescimento técnico, transição de carreira)
   7. Quais habilidades técnicas você já tem?

3. Com as respostas, grave `data/perfil-do-usuario.md` no formato de `data/perfil-do-usuario.exemplo.md`.
4. Confirme à pessoa que o perfil foi salvo e mostre o menu.

## Cuidados

- Peça só o que está na lista. Não peça nome completo, documento, telefone nem endereço.
- Se uma resposta vier vazia ou confusa, pergunte só aquela de novo.
