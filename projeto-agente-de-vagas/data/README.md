# Pasta `data/`

Aqui os agentes guardam o que produzem enquanto trabalham. Esta pasta começa vazia, só com o modelo de perfil.

| Arquivo | Quem grava | Quando |
| --- | --- | --- |
| `perfil-do-usuario.md` | Regente | depois do quiz |
| `resultados-da-busca.md` | Faro | depois da busca de vagas |
| `ranking.md` | Prumo | depois do ranking |

Os três arquivos de verdade ficam **fora do repositório** (veja o `.gitignore`), porque têm dados da sua busca. O repositório traz só `perfil-do-usuario.exemplo.md`; exemplos de resultados e de ranking estão nas pastas da série.
