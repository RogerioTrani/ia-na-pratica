## Como o repositório é organizado

Uma pasta por série e, dentro dela, uma pasta por vídeo, sempre com a mesma estrutura:

- `README.md`: o resultado do vídeo, o que você precisa antes e a lista de arquivos.
- `apostila.md`: o passo a passo escrito.
- `pedidos-e-comandos.md`: os textos e comandos da tela, na ordem, para copiar.
- Arquivos de apoio do vídeo, como planos e exemplos.

## Avisos

- Os planos, perfis, vagas e rankings daqui são **exemplos**. O modelo de IA pode gerar textos diferentes, e tudo bem. Nenhuma vaga, empresa ou nota dos exemplos é real.
- Nunca publique chaves de API nem dados pessoais. As chaves dos vídeos são apagadas; use sempre a sua.
